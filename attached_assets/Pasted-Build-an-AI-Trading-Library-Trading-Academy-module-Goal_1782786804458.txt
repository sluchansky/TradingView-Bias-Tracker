Build an AI Trading Library / Trading Academy module.

Goal:
Give the bot a structured learning system so it can learn trading concepts, strategies, trade management, and failure patterns without changing live execution logic immediately.

Main sections:

1. Knowledge Sources
Allow me to add:
- YouTube video transcript
- Book notes
- Strategy article
- My own trade recap
- Screenshot/chart study
- Backtest result
- Tradzella journal export

Each source should store:
- title
- author/source
- link if available
- market type
- strategy type
- date added
- raw notes/transcript
- AI summary
- trust rating

2. AI Extraction
When a source is added, the bot should extract:
- Core concept
- Market condition it works in
- Entry rules
- Exit rules
- Stop rules
- Trade management rules
- Best time/session
- When to avoid
- Common failure signs
- Example setup
- Whether it applies to scalping or swing trading

3. Strategy Playbook
Turn useful lessons into structured strategy cards.

Each strategy card should include:
- Strategy name
- Setup type
- Long rules
- Short rules
- Required confirmations
- Entry trigger
- Stop placement
- Target logic
- Early exit rules
- Invalid conditions
- Risk notes
- Confidence rating
- Active / Testing / Archived status

4. Validation System
Do not automatically trust any YouTube/book strategy.

Every new lesson should be marked:
- UNTESTED
- BACKTESTING
- PAPER TESTING
- APPROVED
- REJECTED

Only APPROVED strategies can influence live auto-trading.

5. Backtest Connection
Allow each strategy card to be tested against historical trades/data.

Track:
- win rate
- profit factor
- average win
- average loss
- max drawdown
- best market
- worst market
- best time window
- common failure reason

6. Trade Management Library
Create a separate section for exit/management rules.

Examples:
- exit if thesis invalidated
- scratch if no progress after X candles
- exit if VWAP flips against position
- exit if CVD strongly reverses
- reduce risk near opposing zone
- take partial at first liquidity target

The bot should use this to improve open-trade management.

7. Professional Trader Thinking Layer
For every new concept, extract the thinking behind it:
- What is the market trying to do?
- Where is liquidity?
- Who is trapped?
- Where is the best trade location?
- What confirms the idea?
- What proves it wrong?
- How should it be managed?

8. Dashboard UI
Add a Trading Academy page with:
- Add New Source button
- Knowledge Library table
- Strategy Playbook
- Trade Management Rules
- Validation Status
- Best Performing Lessons
- Rejected Lessons
- Search/filter by strategy, market, source, status

9. Safety Rule
The Trading Library is for learning only.

New concepts should not affect live trading until:
- extracted into a strategy card
- tested
- reviewed
- manually approved
- promoted to active status

10. Output
The bot should be able to answer:
- What did we learn from this video?
- What strategy does this teach?
- How would this apply to MGC/MNQ?
- What are the exact rules?
- Has this been tested?
- Should this affect live trading?
- Why or why not?
