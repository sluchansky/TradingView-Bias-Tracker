TASK: Phase 5E — Live Source Attribution Analytics

OBJECTIVE

The Databento Source Attribution Audit is complete.

Do NOT modify production scoring.

Do NOT modify Databento ingestion.

Do NOT modify Edge Score.

Do NOT modify Learning influence.

This phase is analytics and observability only.

The objective is to collect evidence over live trading sessions to determine whether any score components represent duplicate market evidence.

----------------------------------------------------
PART 1 — SESSION ANALYTICS
----------------------------------------------------

Create a diagnostics-only session analytics collector.

For every evaluated setup record:

- timestamp
- instrument
- direction
- final base score
- learning delta
- final score
- verdict
- readiness state

For every scoring component include:

- component name
- points awarded
- source
- source timestamp
- evidence age

Store diagnostics separately from production state.

Never feed analytics back into scoring.

----------------------------------------------------
PART 2 — DUPLICATE EVIDENCE STATISTICS
----------------------------------------------------

Track statistics only.

Examples:

BOS + Confirmation

CHOCH + Confirmation

Volume + Sweep

CVD + Confirmation

Volume + CVD

TradingView + Databento same event

Structure + Confirmation

For every duplicate candidate collect:

- evidence group
- components involved
- sources
- score represented
- occurrence count

Never suppress points.

Never modify verdicts.

----------------------------------------------------
PART 3 — SOURCE DISTRIBUTION
----------------------------------------------------

Track:

Databento sourced components

TradingView sourced components

Internal components

Mixed-source components

Unknown-source components

Produce percentages by:

- instrument
- session
- direction

----------------------------------------------------
PART 4 — COMPONENT CORRELATION
----------------------------------------------------

Measure how often components appear together.

Examples:

BOS + Confirmation

CHOCH + Confirmation

Sweep + Volume

Sweep + CVD

VWAP + Volume

CVD + Volume

Generate a correlation report only.

Do not change scoring.

----------------------------------------------------
PART 5 — DASHBOARD
----------------------------------------------------

Add a new diagnostics panel.

Title:

Source Attribution Analytics

Include:

Source distribution

Duplicate evidence summary

Component correlation

Top duplicate groups

Most common evidence source

Average evidence age

Most recent attribution

Hide behind Diagnostics mode.

Never display during normal trading.

----------------------------------------------------
PART 6 — REPORT
----------------------------------------------------

Generate a report after sufficient live data.

Include:

• Total setups analyzed

• READY setups

• WAIT setups

• Source percentages

• Duplicate candidate frequency

• Component correlation table

• Evidence age statistics

• Mixed-source frequency

• TradingView/Databento duplicate frequency

Most importantly answer:

1. Is Databento already fully represented by existing score components?

2. Are any components repeatedly scoring the same market evidence?

3. Is there statistical justification for a future independent Databento score adjustment?

If the answer cannot be proven from collected data, recommend leaving the current scoring model unchanged.
