Build Option 2: Flag-Gated Learning Demotion with Confidence Governor.

Goal:
The bot should learn from completed trades, but it must NOT change live trading behavior unless I explicitly enable it from the dashboard.

Default behavior:
- Learning Engine collects data.
- Dashboard displays recommendations.
- Live trade behavior remains unchanged.
- Golden tests must remain byte-identical while learning demotion is OFF.

Add dashboard toggle:

learningDemotionEnabled = false by default

When OFF:
- Display learning recommendations only.
- Never downgrade READY trades.
- Never block live trades.
- Never change order behavior.

When ON:
- Learning Engine may only downgrade READY LONG or READY SHORT to WAIT.
- It cannot upgrade WAIT to READY.
- It cannot create new trades.
- It cannot change entry, stop, targets, or contract size.
- It can only reduce confidence or demote weak learned profiles.

Add Confidence Governor.

Instead of a hard veto only, calculate:

baseEdgeScore
historicalWinRateAdjustment
sessionPerformanceAdjustment
marketTypeAdjustment
setupGradeAdjustment
recentPerformanceAdjustment
finalConfidenceScore

Example:

Base Edge Score: 91
Historical Win Rate: +6
Session Performance: +4
Market Type: +3
Setup Grade: +5
Recent Performance: -2
Final Confidence: 107 capped at 100

Or:

Base Edge Score: 88
Historical Win Rate: -15
Choppy Market: -8
Late Entry Pattern: -6
Losing Setup Profile: -12
Final Confidence: 47

Rules:
- Final confidence is capped between 0 and 100.
- If learningDemotionEnabled is OFF, finalConfidenceScore is display-only.
- If learningDemotionEnabled is ON and finalConfidenceScore falls below READY threshold, demote READY to WAIT.
- Always explain why confidence changed.

Add Professional Memory Engine.

Every completed trade should be stored with:

- symbol
- mode
- strategyName
- direction
- entryTime
- exitTime
- sessionWindow
- dayOfWeek
- marketType
- volatilityType
- ATR
- VWAP position
- CVD/delta condition
- trend strength
- Entry Efficiency Score
- Edge Score
- Scalper Grade
- Trade Grade
- entry price
- stop price
- target prices
- exit price
- win/loss/breakeven
- R result
- MFE
- MAE
- slippage
- time in trade
- reason for entry
- reason for exit
- failure reason if loss

Before every new READY setup, compare it to historical trades with similar conditions.

Find similar trades by:
- same symbol
- same mode
- same direction
- similar marketType
- similar sessionWindow
- similar volatilityType
- similar Entry Efficiency Score range
- similar strategyName
- similar VWAP/CVD condition

Return:

similarTradesFound
similarWinRate
averageR
averageMFE
averageMAE
averageHoldTime
mostCommonFailure
memoryRecommendation

Example:

Similar Trades Found: 87
Win Rate: 81%
Average R: +1.18R
Average Hold: 4m 12s
Recommendation: HIGH CONFIDENCE

Example losing profile:

Similar Trades Found: 42
Win Rate: 38%
Most Common Failure: Late breakout after 3-candle expansion
Recommendation: WAIT

Discord READY alerts should include:

- Base Edge Score
- Final Confidence
- Similar Trades Found
- Similar Win Rate
- Memory Recommendation
- Whether learning demotion is OFF or ON

Safety rules:
- Default OFF.
- No live behavior change until toggle is ON.
- Learning engine can only make bot more selective, never more aggressive.
- Never allow learning engine to increase position size.
- Never allow learning engine to override hard risk rules.
- Log every demotion with reason.
