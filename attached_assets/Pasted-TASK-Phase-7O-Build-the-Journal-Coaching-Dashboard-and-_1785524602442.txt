The Journal now supports:

- review workflow
- review queue
- screenshots
- mistake tags
- positive tags
- emotion tags
- ratings

The next goal is to convert reviewed trade data into clear, actionable coaching insights.

PRIMARY GOAL

Build a read-only Journal Coaching dashboard that answers:

- What mistakes are costing the most money and R?
- Which behaviors are associated with better results?
- Which strategies and sessions perform best when the plan is followed?
- Which emotions correlate with poor execution?
- Is discipline improving or declining?
- What should the operator focus on next?

This is analytics and display only.

Do not modify trading logic or learning formulas.

PART 1 — DATA COVERAGE

Every coaching insight must show:

- time period
- reviewed trade count
- eligible sample count
- excluded count
- incomplete review count
- source coverage
- instrument coverage
- mode coverage

Do not present conclusions from incomplete or tiny samples as reliable.

Use minimum-sample warnings.

Suggested states:

INSUFFICIENT DATA
EARLY SIGNAL
MODERATE CONFIDENCE
STRONG EVIDENCE

Use existing project thresholds where available.

Do not invent a threshold without documenting it.

PART 2 — COSTLIEST MISTAKES

Calculate performance by mistake tag.

For each mistake show:

- occurrence count
- win rate
- net P&L
- net R
- average R
- average loss
- total loss attributable
- instruments
- strategies
- sessions
- trend versus prior period

Examples:

CHASED ENTRY
12 occurrences
-5.8R total
Average: -0.48R
Most common: MNQ / Opening Drive / 9:30–10:00 ET

Do not claim causal attribution beyond the actual tagged-trade association.

Label these as associations.
