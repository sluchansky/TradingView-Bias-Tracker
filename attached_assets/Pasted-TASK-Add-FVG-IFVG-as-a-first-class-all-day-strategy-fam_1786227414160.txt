TASK: Add FVG / IFVG as a first-class all-day strategy family inside the SCALP decision machine.

CONTEXT

The system currently relies heavily on structure, VWAP, liquidity, score components, and broad conflict logic.

The operator wants more tradable all-day opportunities and believes Fair Value Gaps (FVG) and inverse FVGs (IFVG) are a better recurring setup family because they occur throughout the session.

The goal is NOT to trade every FVG.

The goal is to model a repeatable sequence:

DISPLACEMENT
→ FVG CREATED
→ PRICE RETURNS
→ HOLD OR FAILURE
→ STRUCTURE/MOMENTUM CONFIRMATION
→ ENTRY WINDOW
→ READY

For inverse FVG:

FVG EXISTS
→ PRICE INVALIDATES/CLOSES THROUGH
→ FVG BECOMES IFVG
→ RETEST FROM OPPOSITE SIDE
→ HOLD
→ STRUCTURE/MOMENTUM CONFIRMATION
→ ENTRY WINDOW
→ READY

This should run all day across supported instruments.

PART 3 — FVG DETECTION RULE
==================================================

Use the existing canonical definition if one exists.

If no canonical definition exists, implement a deterministic three-candle imbalance detector.

For bullish FVG:

- candle 1 high < candle 3 low
- middle candle demonstrates displacement
- resulting zone = candle 1 high → candle 3 low

For bearish FVG:

- candle 1 low > candle 3 high
- middle candle demonstrates displacement
- resulting zone = candle 3 high → candle 1 low

Add quality filters using existing data where appropriate:

- minimum gap size
- ATR-relative size
- displacement strength
- volume expansion
- session relevance

Do not tune numeric thresholds by intuition.

PART 4 — FVG LIFECYCLE
==================================================

Support:

NEW
ACTIVE
TOUCHED
MITIGATED
HOLDING
FAILED
INVERTED
RETESTED
EXPIRED

Definitions must be deterministic.

Example:

ACTIVE
zone exists and has not been meaningfully revisited

TOUCHED
price enters the zone

MITIGATED
price trades sufficiently into the zone according to canonical rule

HOLDING
price interacts with the zone and rejects in original direction

FAILED
price closes through the invalidation boundary

INVERTED
failed FVG becomes valid opposite-direction IFVG candidate

RETESTED
price returns to the inverted zone from the opposite side

EXPIRED
zone aged out or became irrelevant

Keep historical zones visible but separate from active trading state.

PART 6 — IFVG REVERSAL SEQUENCE
==================================================

For bullish IFVG:

BEARISH FVG EXISTS
→ PRICE CLOSES THROUGH / INVALIDATES IT UPWARD
→ BEARISH FVG STATUS = INVERTED
→ BULLISH IFVG CREATED
→ PRICE RETESTS IFVG FROM ABOVE
→ IFVG HOLDS
→ BULLISH STRUCTURE CONFIRMS
→ MOMENTUM CONFIRMS
→ LONG ENTRY WINDOW

Mirror for bearish.

This is important:

A failed FVG should not disappear.

It should become historical evidence and, when rules are met, an opposite-direction IFVG candidate.
