TASK: Phase 8A — Build the Edge Ledger with frozen original-signal accounting.

CONTEXT

The profitability audit identified three CRITICAL trust gaps:

1. Original signal parameters are not frozen.
   Managed stop/target changes can contaminate ghost/paper R.

2. The system does not cleanly separate:
   - strategy signal quality
   - trade-management quality

3. Ghost/paper performance is gross and does not consistently deduct commissions, fees, or slippage.

The goal of this phase is to create a trustworthy, immutable Edge Ledger that measures the original trade idea separately from what the execution manager later did.

IMPORTANT

This phase must NOT:

- tune strategies
- change Edge Score
- change readiness thresholds
- change learning weights
- change live eligibility
- change execution
- change risk
- send live orders

This is accounting, evidence, and diagnostics only.

==================================================
PART 4 — DEFINE SIGNAL OUTCOME
==================================================

Signal Outcome answers:

“Was the original trade call good?”

It must ignore later management changes.

For Long:

- original stop remains original stop
- TP1 remains original TP1
- TP2 remains original TP2

For Short:
same principle mirrored.

Using canonical Databento market data, determine:

- whether entry was actually touched/traded
- whether original stop or target was hit first
- MFE
- MAE
- gross R
- resolution time

Do not assume a fill if price never traded through the entry.

Do not use modified stop or target levels.

==================================================
PART 5 — DEFINE MANAGED OUTCOME
==================================================

Managed Outcome answers:

“How well did execution/management handle the signal?”

Use actual or canonical managed values:

- actual entry
- actual exits
- stop moves
- partial exits
- break-even moves
- trailing stops
- commissions
- fees
- slippage
- final P&L
- final R

Link to native_journal when possible.

Do not overwrite Signal Outcome with Managed Outcome.

PART 7 — SIGNAL VS MANAGEMENT COMPARISON
==================================================

For every resolved trade with both sides available calculate:

signal_gross_r
signal_net_r

managed_gross_r
managed_net_r

delta_r =
managed_net_r - signal_net_r

Classify:

MANAGEMENT_HELPED
MANAGEMENT_HURT
MANAGEMENT_NEUTRAL
COMPARISON_UNAVAILABLE

Example:

Signal Net R: +2.0
Managed Net R: +0.3

Result:
MANAGEMENT_HURT
Delta: -1.7R

Or:

Signal Net R: -1.0
Managed Net R: -0.25

Result:
MANAGEMENT_HELPED
Delta: +0.75R

PART 12 — BACKFILL POLICY
==================================================

Do not blindly backfill historical records.

Classify existing historical data into:

SAFE_TO_BACKFILL
- original entry/stop/targets provably preserved

PARTIAL_BACKFILL
- some original terms known

UNSAFE_TO_BACKFILL
- management mutations make original signal unknowable

Never reconstruct an original stop from the final moved stop.

Report counts in each category.
