CHANGE 1 — VOLATILITY DISPLAY TRUTHFULNESS

Problem:

The gate diagnostic displays:

volAdj=-10

This implies the score was reduced by 10, but current scoring code does not apply that value.

Required fix:

Rename or relabel this diagnostic field so it cannot be mistaken for an applied score adjustment.

Acceptable examples:

* volSuggestedAdj=-10
* volDiagnosticAdj=-10
* volPolicyAdj=-10 (not applied)
* volatilityRegime=Choppy, configuredAdj=-10, appliedAdj=0

Preferred structured output:

volatility: {
regime: “Choppy”,
configured_adjustment: -10,
applied_adjustment: 0,
affects_edge_score: false,
hard_block: false
}

In text logs, render something like:

volatility=Choppy configuredAdj=-10 appliedAdj=0

Do not display only “volAdj=-10.”
