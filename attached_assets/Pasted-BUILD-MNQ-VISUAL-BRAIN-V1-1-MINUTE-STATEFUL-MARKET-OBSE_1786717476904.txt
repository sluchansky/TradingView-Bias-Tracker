BUILD: MNQ VISUAL BRAIN V1 — 1-MINUTE STATEFUL MARKET OBSERVER

GOAL
Create a lightweight visual-market observer that captures the live MNQ TradingView chart once every 60 seconds, sends the image plus recent visual-state history to a vision-capable model, receives strict structured analysis, stores every observation, and displays the current state on the existing dashboard.

IMPORTANT:
- MNQ ONLY for V1.
- SHADOW / OBSERVATION ONLY.
- DO NOT place trades.
- DO NOT modify SCALP or INTRADAY_TREND decision logic yet.
- DO NOT add another strategy.
- Keep implementation small and isolated.
- Reuse existing infrastructure where practical.
- Existing trading engine must continue functioning if Visual Brain fails.

==================================================
1. ARCHITECTURE
==================================================

Create this pipeline:

LIVE MNQ CHART
    ↓
SCREENSHOT EVERY 60 SECONDS
    ↓
VISUAL BRAIN ANALYZER
    ↓
STRICT JSON MARKET STATE
    ↓
STATE COMPARISON / MEMORY
    ↓
DATABASE
    ↓
VISUAL BRAIN DASHBOARD PANEL

The visual analyzer MUST receive:
1. Current screenshot
2. Previous Visual Brain observation
3. Up to the previous 10 observations as compact state history
4. Current timestamp
5. Instrument = MNQ

Do NOT analyze each screenshot independently.

==================================================
2. SCREEN CAPTURE
==================================================

Capture only the TradingView MNQ chart region if possible.

Preferred:
- Browser automation / Playwright screenshot of chart element or fixed crop.

Fallback:
- Desktop screen capture with fixed configured coordinates.

Config:

VISUAL_BRAIN_ENABLED=true
VISUAL_BRAIN_SYMBOL=MNQ
VISUAL_BRAIN_INTERVAL_SECONDS=60

Do not capture faster than once per minute.

Store screenshots temporarily.

Optionally retain only screenshots associated with meaningful state changes to reduce storage.

==================================================
3. VISUAL ANALYSIS
==================================================

Create:

visual_brain.py

Main entry:

analyze_visual_market(
    screenshot,
    previous_state,
    recent_history,
    instrument="MNQ"
)

The model prompt should behave like a disciplined market observer.

It should analyze ONLY what can reasonably be seen from the chart.

Focus on:

- current market structure
- higher highs / higher lows
- lower highs / lower lows
- consolidation/range
- support/resistance interaction
- liquidity sweeps
- breakout
- breakdown
- failed breakout
- failed breakdown
- reclaim
- rejection
- retest
- continuation
- reversal
- momentum expansion
- momentum exhaustion
- chop
- location relative to visible zones
- whether price is approaching or leaving important structure

DO NOT ask the model to predict exact future prices.

Never hallucinate a price.

==================================================
5. STATEFUL MEMORY
==================================================

This is critical.

The observer must compare the current frame to previous frames.

Example sequence from today's MNQ market:

LIQUIDITY_SWEEP
→ BULLISH_RECLAIM
→ REVERSAL_CONFIRMED
→ RESISTANCE_TEST
→ RESISTANCE_REJECTION
→ SECOND_FAILED_PUSH
→ SUPPORT_TEST
→ SUPPORT_BREAKDOWN
→ BEARISH_CONTINUATION

The observer needs to recognize transitions like this.

Never permanently retain an old bullish/bearish opinion merely because an earlier signal occurred.

NEW PRICE ACTION OVERRIDES OLD STATE.
