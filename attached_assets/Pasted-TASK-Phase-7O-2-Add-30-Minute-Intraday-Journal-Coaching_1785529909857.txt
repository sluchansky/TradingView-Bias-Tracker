TASK: Phase 7O.2 — Add 30-Minute Intraday Journal Coaching Analysis.

CONTEXT

Phase 7O delivered Journal Coaching analytics.

Phase 7O.1 added drill-down from coaching insights into the exact supporting trades.

The next goal is to analyze performance and behavior by 30-minute trading block.

PRIMARY QUESTIONS

The system should answer:

- Which 30-minute periods produce the most profit and R?
- Which periods produce the largest losses?
- When is plan adherence strongest?
- When do mistakes and emotional trading increase?
- Which strategies perform best at specific times?
- Are there time periods the operator should avoid or approach cautiously?

This is analytics, filtering, and display only.

PART 1 — DEFINE THE CANONICAL TRADE TIME

Determine which timestamp should assign a trade to a 30-minute block.

Preferred source:

- actual entry or first-fill timestamp

Fallback only when unavailable:

- trade open timestamp

Do not use:

- close time
- import time
- review time
- database insertion time

Document the timestamp source for each trade source:

- strategy_trades
- tradezella_trades
- journal_entries

PART 2 — TIMEZONE

Use one consistent operator-facing timezone.

Preferred:

America/New_York

All bucketing must happen after converting the canonical entry timestamp into the display timezone.

Handle:

- daylight-saving time
- overnight futures sessions
- trades crossing midnight
- imported timestamps with explicit timezone
- imported timestamps without timezone
- malformed timestamps

Do not silently assume UTC for timezone-free imported data unless that is already the importer contract.
