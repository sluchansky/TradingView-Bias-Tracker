MIGRATE THESE COCKPIT BINDINGS

1. Verdict headline
From:
data.verdict

To:
data.brain.decision.verdict

2. Readiness
Remove:
verdict.includes("READY")

Use:
data.brain.decision.is_ready

3. Direction
From:
data.strict_direction and other directional fallbacks

To:
data.brain.decision.direction

4. Edge score
From:
data.edge_score

To:
data.brain.score.value

5. Edge score maximum
Remove all hardcoded /100 assumptions.

Use:
data.brain.score.max

Score bar percentage must be:

value / max * 100

Safely clamp display percentage between 0 and 100.

Do not alter the underlying score value.

6. Edge grade
From:
data.edge_grade

To:
data.brain.score.grade

7. Primary reason
Remove the mixed client priority:

strict_reason ?? main_brain_voice

Use:
data.brain.reasons.top[0]

Render a neutral empty state if no reason is available.

Do not substitute unrelated narrative fields.

8. Next action
From:
data.stage_next_step

To:
data.brain.decision.next_action

9. Trade plan
From:
data.trade_plan

To:
data.brain.trade_plan

Apply this to both:
- suggested levels panel
- trade ticket overlay

When brain.trade_plan is null:
- clear all previous levels
- hide or disable Enter Trade
- show a clear “No actionable trade plan” state

10. Diagnostics drawer score display
From:
edge / 100

To:
brain.score.value / brain.score.max

Do not introduce a second score calculation.

11. Instrument navigation snapshots
For each instrument snapshot use, when available:
- brain.decision.verdict
- brain.decision.is_ready
- brain.score.value

Do not derive READY from verdict text when brain exists.

BACKWARD COMPATIBILITY

Use one whole-contract fallback only when data.brain is entirely absent.

Example:

const brain = data.brain ?? buildLegacyBrainFallback(data);

When data.brain exists, migrated fields must read from brain exclusively.

Do not use mixed per-field fallbacks such as:

brain.score.value ?? data.edge_score

because this can silently mix contracts.

Do not treat 0, false, null, or empty arrays as absent.

Emit one clear console warning when the legacy whole-contract fallback is used.
