TASK: Left Brain Market Intelligence — Production Shadow Validation

OBJECTIVE

Validate the new Left Brain Market Intelligence module using live Databento data without allowing it to influence any trading decision, score, risk rule, order, or TradersPost execution.

DO NOT add new trading logic.

DO NOT connect Left Brain Market Intelligence to:

* direction selection
* edge score
* confidence score
* strategy selection
* entry approval
* vetoes
* position sizing
* stop placement
* target placement
* trade management
* TradersPost
* broker execution

The module must remain diagnostics-only.

STEP 1 — ENABLE SHADOW MODE

Set:

LEFT_BRAIN_MARKET_INTELLIGENCE_ENABLED=1

Confirm the module computes only from the Databento bar-scan thread and stores its output in:

_LEFT_BRAIN_MI_BY_INST

Confirm full_analysis only reads the cached result and does not recompute it.

STEP 2 — ADD DIAGNOSTIC TIMING

Measure and record the execution time of:

compute_market_intelligence(…)

Track per instrument:

* last_runtime_ms
* average_runtime_ms
* maximum_runtime_ms
* run_count
* exception_count
* last_exception
* last_updated_at

The diagnostic timing must not affect any market classification.

Do not add timing fields to directional probabilities or data confidence calculations.

STEP 3 — VERIFY FAIL-OPEN BEHAVIOR

Force or simulate:

* missing bars
* stale bars
* missing VWAP
* missing ATR
* missing volume
* missing CVD or delta
* incomplete session data
* unexpected field types
* internal module exception

For every case:

* full_analysis must still complete
* Right Brain evaluation must still complete
* existing decision output must remain unchanged
* no order path may be blocked
* the Left Brain result may be absent or report reduced confidence
* the exception must be logged with rate limiting

STEP 4 — VWAP AUTHORITY LIVE CHECK

For MGC, MNQ, MES, and MYM, record:

* Databento VWAP
* Databento VWAP age
* chart VWAP
* chart VWAP age
* selected VWAP
* selected source
* selection_correct
* price difference between sources

Confirm:

1. Fresh Databento always wins.
2. A later TradingView webhook cannot replace fresh Databento authority.
3. The two stores remain independent.
4. selection_correct remains true during normal operation.
5. Existing get_vwap() callers receive the expected authoritative VWAP.

Do not change VWAP selection logic during this task unless a reproducible authority failure is found.

STEP 5 — MARKET INTELLIGENCE OUTPUT VALIDATION

For every generated result, verify:

* bullish probability + bearish probability + neutral probability = exactly 100
* data confidence remains between 0 and 100
* no NaN or infinity values
* market state is one of the supported classifications
* session character is one of the supported classifications
* session phase is one of the supported classifications
* playbook families contain no duplicates
* supporting evidence contains no empty values
* missing evidence accurately reflects unavailable inputs
* timestamps are valid
* the ticker/instrument matches the Databento scan instrument

STEP 6 — STABILITY TRACKING

Collect at least one full active market session of shadow observations.

Produce counts by instrument for:

* market state
* session character
* session phase
* auction control
* dominant directional outlook
* average data confidence
* confidence below 40
* confidence from 40 through 69
* confidence 70 or higher
* classification changes per hour
* consecutive identical classifications
* exceptions
* stale-data results

Do not tune thresholds during the observation period.

STEP 7 — CHANGE-FREQUENCY CHECK

Detect whether classifications are flipping excessively from bar to bar.

Report:

* average classification duration
* shortest classification duration
* longest classification duration
* flips per hour
* repeated A → B → A oscillations
* instruments with the most instability

Do not add smoothing in this task. Report the behavior first.

STEP 8 — DECISION-PARITY PROOF

Run identical recorded Databento inputs twice:

Run A:
LEFT_BRAIN_MARKET_INTELLIGENCE_ENABLED=0

Run B:
LEFT_BRAIN_MARKET_INTELLIGENCE_ENABLED=1

Compare all existing trading outputs except the newly added diagnostics fields.

The following must remain identical:

* action
* verdict
* direction
* confidence
* edge score
* selected strategy
* entry
* stop
* targets
* invalidation
* contracts
* prop-rule result
* duplicate guard result
* daily-loss guard result
* execution eligibility
* TradersPost payload
* trade-management instructions

Produce a field-by-field diff.

Expected result:

No differences outside:

* left_brain
* vwap_diagnostics
* diagnostic timing or logging fields

Add focused tests for:

* fresh Databento versus fresh chart VWAP

Run:

* new Left Brain MI tests
