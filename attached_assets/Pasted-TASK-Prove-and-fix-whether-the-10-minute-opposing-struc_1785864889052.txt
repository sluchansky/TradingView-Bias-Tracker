PART 4 — DEFINE UNRESOLVED CONFLICT
==================================================

Opposing structure should block only when it remains unresolved.

Proposed blocking conditions:

ACTIVE opposition

- recent opposing structure exists
- no later confirmed structure shift has superseded it
- price has not reclaimed the relevant level
- opposing direction remains competitive
- event has not expired
- event is not a duplicate refresh

CHALLENGED opposition

- opposing event remains relevant
- newer evidence is challenging it
- not enough proof yet to override
- may remain informational or apply a score penalty
- should not automatically hard-block unless the canonical conflict contract requires it

OVERRIDDEN opposition

- later same-direction BOS/CHOCH or reclaim confirms the candidate direction
- old event remains visible historically
- old event contributes zero block
- old event does not restart its timer

EXPIRED opposition

- outside the window
- contributes no block

Only ACTIVE unresolved opposition should hard-block.

==================================================
PART 5 — OVERRIDE CONTRACT
==================================================

Define a deterministic override.

For a Long candidate, an older bearish event may become OVERRIDDEN when all required evidence exists:

1. A newer bullish structure transition occurs after the bearish event.
2. The bullish event belongs to the same instrument, mode, session, and active setup.
3. Price reclaims the relevant structure/range/VWAP level when applicable.
4. The newer event is not a duplicate.
5. The bullish evidence has not already expired.
6. No still-newer bearish structure reactivates the conflict.

Mirror for Short.

Do not require the old event to age beyond 10 minutes before it can be overridden.
