TASK: Reframe Task #83 — Build the native in-dashboard journal as the primary source of truth, with Tradzella only as a migration/import source.

CONTEXT

Task #82 created immutable trade snapshots at send time.

The long-term goal is for every trade to:

- originate in the platform
- pass through the execution gateway
- be managed through the dashboard
- close through the platform
- update the native journal automatically
- become available for review and learning

Tradzella should not remain the primary journal.

It should only support:

- importing historical trades
- reconciling missing fills or fees
- migration from the old workflow
- optional verification against external records

GOAL

Build the native Journal so every platform trade automatically becomes a complete journal record from planning through final outcome.

STRICT SCOPE

- strategy logic
- Edge Score

- Databento ingestion
- risk thresholds

- authentication
