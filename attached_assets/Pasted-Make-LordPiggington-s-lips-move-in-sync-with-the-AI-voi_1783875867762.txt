CONNECT TO THE REAL VOICE AUDIO

The same HTMLAudioElement used to play the AI response must be passed to the avatar lip-sync system.

Example:

<LordPiggingtonAvatar
  audioElement={voiceAudioRef.current}
  isSpeaking={isSpeaking}
/>

Use the Web Audio API:

1. Create an AudioContext.
2. Create a MediaElementAudioSourceNode from the voice audio element.
3. Connect it to an AnalyserNode.
4. Connect the analyser to audioContext.destination so sound still plays.
5. Read the audio volume every animation frame.
6. Convert the current volume into a mouth-open value from 0 to 1.
7. Apply that value to the VRM mouth expressions.
8. Smooth the movement so the mouth does not chatter.
9. Reset every mouth expression to zero when audio pauses, ends, or errors.

IMPORTANT:
Create MediaElementAudioSourceNode only once for each audio element. Do not recreate it every render or animation frame.

IMPLEMENT A LIP-SYNC CONTROLLER SIMILAR TO THIS:

type MouthExpression = "aa" | "ih" | "ou" | "ee" | "oh";

const mouthExpressions: MouthExpression[] = [
  "aa",
  "ih",
  "ou",
  "ee",
  "oh"
];

function resetMouth(vrm) {
  if (!vrm?.expressionManager) return;

  for (const expression of mouthExpressions) {
    if (vrm.expressionManager.getExpression(expression)) {
      vrm.expressionManager.setValue(expression, 0);
    }
  }
}

function setMouthShape(vrm, selectedExpression, amount) {
  if (!vrm?.expressionManager) return;

  for (const expression of mouthExpressions) {
    if (!vrm.expressionManager.getExpression(expression)) continue;

    const target = expression === selectedExpression ? amount : 0;
    const current =
      vrm.expressionManager.getValue(expression) ?? 0;

    const smoothed = THREE.MathUtils.lerp(
      current,
      target,
      0.35
    );

    vrm.expressionManager.setValue(expression, smoothed);
  }
}

AUDIO ANALYSIS:

const audioContext = new AudioContext();

const analyser = audioContext.createAnalyser();
analyser.fftSize = 256;
analyser.smoothingTimeConstant = 0.65;

const source =
  audioContext.createMediaElementSource(audioElement);

source.connect(analyser);
analyser.connect(audioContext.destination);

const frequencyData =
  new Uint8Array(analyser.frequencyBinCount);

Inside the existing Three.js animation loop:

analyser.getByteFrequencyData(frequencyData);

let total = 0;

for (let i = 0; i < frequencyData.length; i++) {
  total += frequencyData[i];
}

const average = total / frequencyData.length;

const noiseFloor = 8;
const speechLevel = 55;

let mouthAmount = THREE.MathUtils.clamp(
  (average - noiseFloor) / speechLevel,
  0,
  1
);

mouthAmount = Math.pow(mouthAmount, 0.8);

Add a small silence threshold:

if (
  audioElement.paused ||
  audioElement.ended ||
  average < noiseFloor
) {
  mouthAmount = 0;
}

SELECTING MOUTH SHAPES

For the first working version, choose different vowel expressions based on frequency ranges rather than opening only one expression constantly.

Example:

let mouthShape: MouthExpression = "aa";

const low =
  averageFrequencyRange(frequencyData, 0, 8);

const middle =
  averageFrequencyRange(frequencyData, 8, 24);

const high =
  averageFrequencyRange(frequencyData, 24, 55);

if (high > middle && high > low) {
  mouthShape = "ee";
} else if (middle > low) {
  mouthShape = "ih";
} else if (mouthAmount > 0.65) {
  mouthShape = "aa";
} else {
  mouthShape = "oh";
}

setMouthShape(
  vrm,
  mouthShape,
  mouthAmount * 0.9
);

Do not activate all vowels at full strength simultaneously because that will distort the face.

- Disconnect the analyser and source nodes.
- Reset the mouth expressions.
- Close the AudioContext if this component owns it.
- Do not create duplicate audio nodes after React rerenders.
