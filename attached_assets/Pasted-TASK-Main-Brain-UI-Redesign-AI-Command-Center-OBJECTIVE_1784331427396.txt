TASK: Main Brain UI Redesign — AI Command Center

OBJECTIVE

Redesign the Main Brain section to feel like the command center of the entire dashboard.

DO NOT remove any existing functionality.

DO NOT remove any existing information.

DO NOT change:

- Trading logic
- Confidence
- Edge scoring
- AI reasoning
- Trade management
- Learning system
- Avatar intelligence
- Backend
- APIs
- Database

This is a visual redesign only.

Think Apple + Palantir + JARVIS.

The goal is to make the Main Brain feel like ONE intelligent system instead of a collection of stacked widgets.

--------------------------------------------------
1. ONE UNIFIED COMMAND CENTER
--------------------------------------------------

The Main Brain should become one cohesive experience.

Do NOT look like multiple independent cards.

Instead create one large integrated panel with visual sections.

The user should immediately understand:

• What the AI sees
• What the AI thinks
• What the AI is waiting for
• What happens next

Everything else supports those four ideas.

--------------------------------------------------
2. MAKE THE AVATAR THE CENTERPIECE
--------------------------------------------------

The avatar should visually anchor the entire Main Brain.

Increase its visual importance.

Do not make it enormous.

Instead:

- larger
- cleaner
- centered
- surrounded by subtle depth

Use:

• soft radial glow
• holographic ring
• gentle animated pulse
• ambient lighting

Never flashy.

Never distracting.

The avatar should feel like the AI powering the dashboard.

--------------------------------------------------
3. REMOVE THE "STACK OF BOXES" FEEL
--------------------------------------------------

Currently every section is inside another bordered rectangle.

Reduce visual clutter.

Replace unnecessary borders with:

- spacing
- typography
- alignment
- subtle separators
- lighting

Use cards only where they improve readability.

The Main Brain should feel like one workspace instead of ten widgets.

--------------------------------------------------
4. CREATE VISUAL HIERARCHY
--------------------------------------------------

The eye should naturally flow through the interface.

Priority order:

1. Avatar
2. Current AI statement
3. Current state
4. Confidence
5. AI reasoning
6. Supporting information
7. Historical information

Nothing should compete equally.

The user should know what matters within one second.
