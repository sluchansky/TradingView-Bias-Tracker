5. The active pill must remain visually highlighted.

6. Add a section heading immediately below the pills.

Example:

When BRAIN is selected:

- BRAIN pill remains highlighted
- heading displays “BRAIN”
- only Brain-assigned panels are visible

8. Switching sections must not reset:

- selected instrument
- sensitivity
- alert state
- auto-trade state
- active setup
- current recommendation
- open panel state
- current API data

9. Save the active section in localStorage.

Use a key similar to:

dashboard-active-section

10. On refresh, restore the last valid selected section.

11. If the stored value is missing or invalid, default to:

overview

==================================================
ACTIVE PILL STYLING
==================================================

The selected pill must have a clearly different state.

Active pill:

- filled or brighter background
- accent border
- high-contrast text
- optional subtle glow
- aria-selected="true"
- tabindex="0"

Inactive pill:

- dark or transparent background
- muted text
- no glow
- aria-selected="false"

Do not rely only on a tiny color difference.

==================================================
ACCESSIBILITY
==================================================

Treat the pill row as a tab-style navigation control.

Requirements:

- container role="tablist"
- each pill role="tab"
- active pill aria-selected="true"
- inactive pills aria-selected="false"
- visible keyboard focus style
- Left Arrow and Right Arrow move between pills
- Enter and Space activate the focused pill
- active panel container may use role="tabpanel"

Do not remove normal mouse or touch behavior.

==================================================
MOBILE REQUIREMENTS
==================================================

Requirements:

- pill row may scroll horizontally

- selected pill should scroll into view after activation
- pill labels must not be clipped
- section heading must remain readable
- only the active section’s panel stack should appear
- inactive panels must not leave blank vertical gaps
- one-column card layout must remain intact
- switching sections must not jump the user to a random page position

Preferred behavior:

After section selection, scroll only enough to keep the active pill and section heading visible.

Do not force-scroll the user to the top of the entire page unless required.
