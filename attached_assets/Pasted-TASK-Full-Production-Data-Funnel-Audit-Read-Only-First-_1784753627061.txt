TASK: Full Production Data Funnel Audit — Read Only First

OBJECTIVE

Determine why the recently published production dashboard is not showing useful, fresh, or complete trading data.

This is an audit and diagnosis task first.

DO NOT make code changes until the complete data path has been mapped and the exact failure points have been proven.

PRIMARY QUESTION

For every incoming TradingView alert or external market-data event:

1. Did production receive it?
2. Was the payload complete?
3. Was it parsed correctly?
4. Was it assigned to the correct instrument and timeframe?
5. Was it stored?
6. Was it included in the current market-state cache?
7. Did the decision engine consume it?
8. Did it produce a decision trace?
9. Did the API return it?
10. Did the current published dashboard display it?

IMPORTANT SCOPE

Audit all currently supported instruments and modes, including at minimum:

* MNQ
* MGC
* MES
* MYM
* SCALP
* SWING
* MICRO SCALP, if still active
* Breakout mode, if still active

Do not assume that a successful HTTP 200 means the data was useful.

Compare:

* Current Git working-tree HEAD
* GitHub main
* Replit internal main
* Deployed production revision

Report any mismatch clearly.

Do not republish yet.
