=========================================================
NO-LOGIC DASHBOARD RULE
=========================================================

The Main Brain route must not:

- generate new theses
- calculate new verdicts
- rescore strategies
- update learning
- write Journal records
- modify active trades
- invoke the gateway
- call the broker
- alter Databento ingestion
- mutate caches
- update timestamps merely because the dashboard was viewed

It may:

- read canonical interfaces
- copy dictionaries
- serialize existing values
- combine existing payloads
- provide availability metadata
- provide explicit nulls
- format display-safe labels

=========================================================
AVAILABILITY CONTRACT
=========================================================

The dashboard must remain available when one subsystem fails.

Design availability reporting such as:

"availability": {
  "left_brain": {
    "available": true,
    "stale": false,
    "updated_at": "..."
  },
  "coach": {
    "available": false,
    "error": "coach_unavailable"
  }
}

Do not let a Coach, Journal, learning, broker, or optional analytics failure
produce a total Main Brain HTTP 500.

Document required fault-isolation tests.
