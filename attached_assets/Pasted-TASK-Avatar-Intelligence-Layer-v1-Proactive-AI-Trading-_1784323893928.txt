TASK: Avatar Intelligence Layer v1 (Proactive AI Trading Partner)

OBJECTIVE

Transform the avatar from a reactive chatbot into an intelligent trading partner.

The avatar should proactively explain the current market, current production decision, and current trade status using ONLY existing production data.

THIS IS A DISPLAY LAYER.

DO NOT MODIFY:

- Decision Pipeline V2
- Strategy logic
- Edge score calculations
- Confidence calculations
- Entry logic
- Exit logic
- Risk management
- TradersPost payloads
- Broker payloads
- Alert routing
- Existing production calculations

The avatar may READ production data but may NEVER change it.

==================================================
PART 1 — AVATAR STATUS ENGINE
==================================================

Create an Avatar Intelligence Engine that continuously watches existing production outputs.

Whenever production data changes, refresh the avatar state without recalculating market logic.

Track:

• Current instrument
• Trading mode
• Current market session
• Production verdict
• Confidence
• Edge score
• Trend direction
• Market structure
• VWAP status
• Zone status
• Active position
• Pending orders
• Entry
• Stop
• Targets
• Invalidation
• Latest alert
• Last production update

This engine is READ ONLY.

==================================================
PART 2 — PROACTIVE SPEECH
==================================================

The avatar should no longer wait for every question.

When meaningful events occur, generate short conversational updates.

Examples:

Dashboard opens

"Welcome back.

MNQ is currently waiting for confirmation.

Trend remains bullish but VWAP has not confirmed.

I'll keep watching."

------------------------------------

Production verdict changes

"We just received new confirmation.

Confidence increased to 87%.

The setup is almost ready."

------------------------------------

READY

"We now have a LONG READY setup.

Entry is available.

Risk parameters remain unchanged."

------------------------------------

WAIT

"We're still waiting.

The strongest confirmation is structure.

The weakest confirmation remains volume."

------------------------------------

Trade opened

"We are now in a live trade.

Current stop and targets remain unchanged."

------------------------------------

TP1 reached

"Target one has been achieved.

Monitoring the remaining position."

------------------------------------

Trade closed

"The trade has completed.

I'll include it in the weekly performance summary."

Keep announcements short.

Never spam repeated announcements.

==================================================
PART 3 — MARKET SUMMARY
==================================================

When the user asks:

"How's the market?"

Generate a natural summary using existing production data.

Example:

"Gold continues to show relative strength while Nasdaq remains range bound.

The current production verdict is WAIT because VWAP confirmation is still missing.

Confidence is moderate."

Do not invent market information.

==================================================
PART 4 — WHY PANEL
==================================================

The avatar should always be capable of answering:

Why WAIT?

Why READY?

Why confidence is low?

What needs to happen next?

What invalidates this?

What changed recently?

Use existing production fields only.

==================================================
PART 5 — EXPLAIN LIKE I'M NEW
==================================================

Add a Simple Explanation mode.

If the user says:

Explain simply.

Explain like I'm new.

What does that mean?

The avatar should rewrite the previous response in beginner-friendly language without changing the facts.

==================================================
PART 6 — NATURAL CONVERSATION
==================================================

Support conversational references.

Examples:

"What about Gold?"

"What changed?"

"Compare to yesterday."

"Explain that."

"Is this safer?"

"What worries you most?"

The avatar should understand context from the existing conversation session.

==================================================
PART 7 — DAILY GREETING
==================================================

When the dashboard opens for the first time each day:

Generate a greeting.

Example:

"Good morning Stephen.

Markets are opening quietly.

Nothing actionable yet.

I'll notify you when something important changes."

Only once per day.

==================================================
PART 8 — PERSONALITY
==================================================

The avatar should sound like a professional trading partner.

Characteristics:

• Calm
• Confident
• Concise
• Honest
• Never dramatic
• Never overconfident
• Never promises outcomes

Avoid phrases like:

"This trade will win."

"This is guaranteed."

Instead say:

"This setup currently has the highest confidence."

==================================================
PART 9 — EVENT QUEUE
==================================================

Prevent repetitive announcements.

If multiple production updates occur quickly:

Queue them.

Combine them into one concise summary.

Do not speak every small update.

==================================================
PART 10 — VOICE
==================================================

Improve speech timing.

Avatar should:

Start talking naturally.

Pause correctly.

Stop immediately if user interrupts.

Resume normal conversation afterward.

Mouth animation should match speaking state.

==================================================
PART 11 — FUTURE MEMORY PLACEHOLDER
==================================================

Create a placeholder service for future trading memory.

Do NOT implement learning yet.

Only define interfaces.

Future examples:

"Last week's Gold setups performed well."

"This strategy has improved recently."

No learning in this phase.

==================================================
PART 12 — PERFORMANCE
==================================================

Do not poll excessively.

Reuse existing production state.

No duplicate API calls.

Do not block alert processing.

Avatar failures must never interrupt trading.
