FIX THE BINDINGS

Use safe explicit reads:

Do not treat 0, false, null, or empty arrays as equivalent.

NARRATIVE

Populate [data-testid="main-brain-narrative"] with a deterministic short
narrative.

Required behavior:

- always produce visible text when brain exists
- maximum three short sentences
- no raw object rendering
- no "[object Object]"
- no raw keys like structure_confirmed

Example formatter:

const primaryReason =
  typeof reasons[0] === "string"
    ? reasons[0]
    : "";

const narrativeParts = [
  instrument && `${instrument} is ${String(verdict).toLowerCase()}.`,
  primaryReason,
  nextAction && `Next: ${nextAction}`
].filter(Boolean);

narrativeEl.textContent =
  narrativeParts.join(" ") || "Brain analysis is available.";

If a reason item is an object, extract a human-readable field explicitly or
skip it. Never stringify the object implicitly.
